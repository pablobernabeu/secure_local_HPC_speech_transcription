# Runtime and evaluation requirements (loose floors)

#
# This file states what the code needs, as >= floors. It is not a record of
# the environment that produced the committed results; that belongs in a
# lock file taken from the ARC environment (requirements-lock.txt, audit
# finding DEPS-01). Development tools (pytest and the ruff linter)
# are in requirements-dev.txt.
#
# Every entry below is used somewhere in the repository. Packages that
# nothing used at the time (openai-whisper, since restored for whisper_norm
# below; torchvision, speechbrain, noisereduce,
# audiomentations, pydub, ffmpeg-python, pandas, pathlib2, pyyaml,
# configparser, tqdm, scikit-learn, matplotlib, seaborn, psutil,
# memory_profiler) and a duplicate numpy line were removed (audit finding
# DEPS-11). Libraries that pyannote.audio or transformers need themselves are
# still installed by them.

# Core Dependencies
# -----------------

# Deep Learning Framework
torch>=2.0.0
torchaudio>=2.0.0

# Speech Recognition and Processing
# 4.56.0 is the floor. WhisperGenerationMixin.detect_language, which the
# post-processing language gate uses to decide whether a transcript is
# English, needs 4.45; evaluation/benchmark_timestamps.py passes dtype= to
# pipeline(), which is accepted only from 4.56 (audit finding DEPS-10).
# preflight._TRANSFORMERS_FLOOR holds the same value. The ASR pipeline's own
# return_language reporting is deliberately not used: between 4.48 and 5.6
# the generation path strips the language token before the tokenizer sees
# it, so that field is None on those versions. The ARC job environment runs
# 4.57.1 (requirements-lock.txt).
transformers[torch]>=4.56.0
huggingface_hub>=0.15.0

# Audio Processing and Analysis
librosa>=0.10.0
soundfile>=0.12.0
scipy>=1.10.0
numpy>=1.24.0

# Compressed-format decoding (.m4a etc.) through a bundled ffmpeg
imageio-ffmpeg>=0.4.8

# Enhanced Name Masking
names-dataset>=3.0.0

# Document Processing
python-docx>=0.8.11

# Speaker Diarization (optional at run time - for --speaker-attribution)
# Setup: run 'python setup/setup_pyannote.py' for guided configuration.
# Requires: HuggingFace token with model access.
# See: PYANNOTE_SETUP_GUIDE.md for detailed instructions.
# Capped below 4: the diarisation loader, the DER scripts and the fine-tuning
# script target the 3.x API, and every committed result used 3.4.0
# (requirements-lock.txt).
pyannote.audio>=3.1.0,<4

# Evaluation / benchmarking
jiwer>=3.0.0
datasets>=2.14.0
# The whisper_norm scoring condition loads openai-whisper's own English
# spelling table (whisper/normalizers/english.json) and checks its SHA-256
# before use, refusing to run without it; the pin is exact so the file, and
# with it every whisper_norm number, cannot change under a re-install. It is
# the version in the ARC job environment (requirements-lock.txt).
openai-whisper==20250625
# Only evaluation/finetune_pyannote_segmentation.py imports this.
pytorch-lightning>=2.0

# Bibliography preprocessing (sentence-case enforcement for references.bib)
# Capped below 2: tools/bib_sentencecase.py imports the 1.x modules
# bibtexparser.bparser and bibtexparser.bwriter, which bibtexparser 2
# replaces; the environment runs 1.4.4 (audit finding DEPS-10).
bibtexparser>=1.4,<2

# Optional: zero-shot NER for the second masking stage.
# The name dictionary can only redact names it already holds, and recall on
# names outside it is zero by construction. Installing this adds a small
# CPU model that recognises people from context, raising recall at some cost
# in precision (see docs and `python -m evaluation.benchmark_masking --ner`).
# Deliberately left commented: it pulls a further model download, and the
# workflow is fully functional without it.
# gliner==0.2.28  (the version the committed NER results reproduce with)
