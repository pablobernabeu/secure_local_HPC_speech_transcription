# Historical infographic

The NotebookLM infographic in this directory was displayed at the top of
the project README until 6 October 2026. It is retained as a historical
artefact, with its original bytes, and is not a summary of the evaluated
workflow.

Its claims that local processing ensures full GDPR compliance, that cloud
processing makes replication impossible, and that the workflow removes
AI-generated errors exceed the evidence reported in the manuscript. Its
claim of unlimited scale also exceeds the measured runs. Institutional
custody is one part of data governance; name masking and speaker attribution
have measured errors, and automatic transcript review supplies advisory flags.

Current descriptions and limitations are in the project README and
`manuscript/manuscript.qmd`. The repository privacy review is recorded in
`docs/privacy_review.md`.
